# Английский: справочник и тренажёры

Статический сайт без зависимостей и без сборки на стороне пользователя.
Исходники разложены по папкам, `index.html` собирается из них одной командой.

## Структура

```
english/
├── index.html              ← собранный файл (его и публикуем)
├── build.py                ← сборщик
├── README.md
└── src/
    ├── template.html       каркас страницы с метками для подстановки
    ├── styles/
    │   └── app.css         палитра, компоненты, мобильный режим
    ├── scripts/
    │   ├── core.js         меню, роутинг, тема, поиск
    │   ├── progress.js     уровни слов, озвучка, микрофон
    │   ├── pages.js        логика главной и словаря
    │   └── trainer.js      логика пяти тренажёров
    ├── data/
    │   ├── vocabulary.js   974 слова в 34 темах
    │   └── exercises.js    задания и неправильные глаголы
    └── content/
        ├── app-pages.html  разметка главной, словаря, тренажёров
        └── grammar.html    16 разделов справочника
```

## Сборка

```
python3 build.py
```

Сборщик подставляет части из `src/` в `src/template.html` и пишет `index.html`.
Питон нужен только для этого шага — сайту он не нужен вообще.

Вывод сборщика показывает размер файла и сводку по содержимому, так что сразу
видно, что материал подхватился.

## Почему один файл на выходе

Сайт публикуется как артефакт по постоянной ссылке, а там нужен один
самодостаточный файл. Заодно это упрощает GitHub Pages: кладёшь `index.html` в
корень репозитория, включаешь Pages — и всё работает, без путей и настроек.

Работать при этом удобно с исходниками: правишь нужный файл в `src/`, запускаешь
сборку.

## Публикация на GitHub Pages

1. Создай репозиторий, например `english`.
2. Загрузи содержимое этой папки.
3. Settings → Pages → Source: Deploy from a branch → `main` → `/ (root)`.
4. Через минуту сайт будет на `https://ЛОГИН.github.io/english/`.

## Что внутри

**Справочник: 16 разделов в 5 группах.** Времена (обзор всех двенадцати,
настоящие, прошедшие, будущие, как выбрать, согласование, глаголы-состояния),
глагол (неправильные глаголы, причастия), части речи (местоимения, числительные,
степени сравнения), структуры (вопросы, предлоги, который час), проверка
(типичные ошибки).

**Словарь: 974 слова в 34 темах**, у каждого транскрипция и заметка о ловушке.

| Набор | Слов | Тем |
|---|---|---|
| Разговорные темы | 802 | 28 |
| Из домашек | 172 | 6 |

Разговорные темы: числа и цвета, время и даты, базовые глаголы, глаголы движения,
фразовые глаголы, еда и напитки, ресторан и кафе, дом и быт, семья и люди, одежда,
город и места, транспорт и поездки, работа и профессии, учёба и школа, здоровье и
тело, природа и погода, животные, технологии, спорт и хобби, кино и музыка, покупки
и деньги, чувства и характер, прилагательные, наречия, связки и служебные, общение,
направления, страны и языки.

Из домашек: глаголы, существительные, прилагательные и наречия, фразы, города и
рынки, легко перепутать.

Повторы по слову убираются автоматически: если слово попало в два набора,
в словаре останется первое вхождение.

**Тренажёры:** карточки со свайпом, написание, произношение, раскрытие скобок
(78 заданий), перевод (40 предложений).

## Уровни слов

Прогресс считается сам по ответам в тренажёрах. У каждого слова три уровня:

| Уровень | Как попасть | Когда вернётся |
|---|---|---|
| Не выучено | начальное состояние | сразу |
| Повторение | 3 верных ответа подряд | через 2 дня |
| Выучено | ещё 3 верных ответа подряд | через 10 дней |

Ошибка опускает слово на ступень вниз и обнуляет серию. Уровень можно поставить
и вручную: в словаре нажми на значок уровня, он переключается по кругу.

В тренажёрах включён режим «только те, что пора повторить» — в колоду попадают
слова с наступившим сроком. Если таких нет, берётся вся выборка по темам.

Параметры меняются в начале `src/scripts/progress.js`:

```js
UP: 3,              // верных подряд для повышения
DELAY: [0, 2, 10],  // задержка в днях по уровням
```

## Перенос прогресса

Раздел «Словарь», кнопка **Сохранить прогресс в файл** — скачивается JSON с
уровнями, статистикой и выбранными темами. На другом устройстве **Загрузить из
файла**. При слиянии выигрывает более высокий уровень, так что данные не
затираются.

Формат файла:

```json
{
  "app": "english-trainer",
  "version": 1,
  "savedAt": "2026-09-29T10:00:00.000Z",
  "progress": {
    "look forward to": {"l":1,"s":2,"r":5,"w":1,"d":1790000000000,"t":1789900000000}
  },
  "trainerStats": {},
  "topics": []
}
```

`l` — уровень, `s` — текущая серия верных, `r` и `w` — сколько раз ответил верно
и с ошибкой, `d` — когда слово вернётся, `t` — когда отвечал в последний раз.

## Звук и микрофон

**Озвучка** (Web Speech Synthesis) работает во всех современных браузерах. Кнопка
динамика есть на карточках, в словаре, в «Написании» и в «Переводе».

Главная ловушка: если на устройстве нет английского голоса, браузер читает
английские слова русским синтезатором — выходит «ком бэк» вместо «кам бэк».
Поэтому голос выбирается явно, с предпочтением британского и локального
(офлайн-голоса обычно чище сетевых).

В разделах «Произношение» и «Словарь» есть панель выбора голоса со списком всех
английских, что нашлись на устройстве, и кнопкой «Проверить» — должно прозвучать
«кам бэк». Выбор сохраняется.

Если английского голоса нет вовсе, панель показывает, как его добавить:

| Система | Путь |
|---|---|
| Windows | Параметры → Время и язык → Речь → Добавить голоса → English |
| Android | Настройки → Язык и ввод → Синтез речи → Google → Установить языки |
| iPhone | Настройки → Универсальный доступ → Устный контент → Голоса → English |
| macOS | Системные настройки → Универсальный доступ → Устное содержимое → Управление голосами |

**Распознавание речи** (Web Speech Recognition) есть в Chrome, Edge и Safari, в
Firefox нет. Требует защищённого соединения: работает по адресу `https` и на
`localhost`, но не при открытии файла с диска. В Chrome распознавание идёт через
серверы Google, поэтому нужен интернет.

Где используется:

- **Произношение** — отдельный тренажёр: показывается перевод, ты говоришь слово
  вслух, микрофон проверяет. Берутся слова не длиннее четырёх слов — длинные
  фразы распознаются плохо.
- **Написание** — кнопка «Сказать» надиктовывает ответ вместо клавиатуры.

Проверка сравнивает произнесённое сразу с несколькими вариантами распознавания и
допускает расхождение в один-два символа. Если микрофон недоступен, раздел честно
объясняет причину, а озвучка продолжает работать.

## Навигация и цвет

Слева меню со сворачиваемыми группами, открытые запоминаются. У каждой группы
свой цвет — он же в бейдже над заголовком, в полоске карточек, в подчёркивании
подзаголовков. По цвету видно, где находишься, не читая текст.

Поиск в шапке ищет и по разделам справочника, и по словам: выбираешь слово —
открывается словарь с уже введённым запросом.

Темы оформления: светлая по умолчанию, кнопка в шапке переключает на тёмную.

## Как пополнять

**Новое слово** — строка в любой массив внутри `src/data/vocabulary.js`:

```js
{en:"look forward to", tr:"/lʊk ˈfɔːwəd tuː/", ru:"с нетерпением ждать",
 note:"дальше -ing форма", topic:"Фразовые глаголы", set:"basic"},
```

Новая тема создаётся сама: напиши её в поле `topic`, и она появится в фильтрах
словаря и в настройках тренажёра.

**Новое задание на скобки** — строка в `GAPS` в `src/data/exercises.js`:

```js
{q:"By next year I ___ here for ten years.", v:"work",
 a:["will have been working"], why:"Срок к моменту в будущем.", t:"future"},
```

`t` — тема фильтра: `present`, `past`, `future`, `participle`.

**Новый раздел справочника** — блок в `src/content/grammar.html`:

```html
<div class="page" id="articles" data-group="Части речи" data-title="Артикли">
  <h2>Артикли</h2>
  <p class="lede">Короткое описание.</p>
</div>
```

Меню соберётся само: пункт появится в указанной группе и получит её цвет.
Группы и их цвета заданы в `src/scripts/core.js`, объект `GROUPS`.

После любой правки — `python3 build.py`.

## Мобильный режим

Ниже 900 px: меню в шторку (бургер, крестик, Esc, тап по затемнению, смахивание
влево), нижняя панель переходов, фильтры одной прокручиваемой лентой, таблицы
превращаются в карточки, поля ввода и кнопки на всю ширину, шрифт полей 16 px
(иначе iOS зумит страницу), учтены вырез экрана и полоса жестов.

## Где хранится прогресс

В `localStorage` браузера: уровни слов (`progress-v1`), статистика тренажёров,
выбранные темы, тема оформления, состояние групп меню. Привязано к одному
браузеру — для переноса используй выгрузку в файл.
